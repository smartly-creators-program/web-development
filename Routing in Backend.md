# Routes: The Map Behind Every URL

## Routes:
A path that connects a specific URL to a page or action in a web application.

## Real Life Analogy:
Route = Address 🏠 --> Tells where to go.

App = Postman  📬  --> Follows the route to deliver the right page or data.

## Example:
Visit http://localhost:3000/  -->  sees Home Page
