# What is JavaScript?

▸ Abbreviation- js [1995]

▸
The only programming language our web browsers understand natively.

▸ JavaScript is the **universal language of interaction**. In browsers, it's the conductor making web pages respond to your clicks. On servers with Node.js, it's the engine powering backends, APIs, and real-time systems. 

> One language, two worlds.

### TL;DR
▸
JavaScript makes web pages **interactive** and **dynamic** (clicks, animations, forms)

▸
It runs in your browser (client-side) and on servers (Node.js)

▸
Named after Java for **marketing**, but they're completely different languages

▸
**Node.js** (2009): JavaScript escapes the browser and ignites servers

▸
One syntax, two runtimes—**isomorphic** JavaScript everywhere
